ASChat

ASChat is a private, self-hosted messaging companion used by a small team. It runs on the owner's own server and is not offered to the public.

Google Drive access (scope drive.file) is used only to back up media files of the owner's own conversations into the owner's own Google Drive. ASChat can only see files it created itself.

Privacy Policy
